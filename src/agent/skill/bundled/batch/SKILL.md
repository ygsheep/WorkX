# Batch — 批量处理

把"逐个手写重复动作"改为"先立模式，再成批推进，最后核对"。

## 1. 明确条目与流程

- 界定**条目清单**（来自哪、共多少条）

- 界定**对每条执行的统一流程**（输入 → 处理 → 期望产出的每个条目判定标准）

## 2. 抽样小批量验证模式

不要一开始就全量跑：

- 先对 **2\~3 条**执行完整流程

- 确认流程正确、判定标准可判定

- 必要时修整流程与标准，再继续

## 3. 成批执行

- 按序（或安全的并行）逐条执行

- 每条记录**通过/失败/跳过**及关键结果，避免只报总数丢了失败细节

## 4. 汇总核对

完成后给出：

- 总数 / 通过 / 失败 / 跳过

- 失败条目列表 + 失败原因归类

- 失败是否影响全局结论；重复性失败是否值得单独排查

## 纪律

- 每条处理尽量独立，一条失败不阻断其余

- 抽样阶段发现流程不稳就不要硬推全量

- 报告给出失败条目明细，而非仅一个通过率
