# Markdown 语法演示

这是一个展示 Markdown 转 TUI 字符画渲染的演示文件。涵盖了标题、段落、换行、强调、列表、代码块、分隔线、转义反引号和表格等语法。

## 1. 标题语法

Markdown 支持 6 级标题：

### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

## 2. 段落与换行

这是第一段的第一行。
这是第一段的第二行（行尾两个空格实现软换行）。  
这是第二段（上方有一个空行）。

段落之间需要用空行分隔。没有空行的多行文本会被视为同一段落。

## 3. 强调语法

Markdown 支持多种行内强调：

- **粗体文本** 使用双星号
- *斜体文本* 使用单星号
- ***粗斜体文本*** 使用三星号
- ~~删除线文本~~ 使用双波浪线
- `行内代码` 使用反引号

也可以混合使用：**粗体中有 *斜体* 文本** 和 ~~删除线中有 `代码`~~。

## 5. 列表语法

### 无序列表

- 第一项
- 第二项
  - 嵌套子项 A
  - 嵌套子项 B
- 第三项

### 有序列表

1. 第一步
2. 第二步
3. 第三步

### 混合列表

1. 有序项一
   - 无序子项
   - 无序子项
2. 有序项二

## 7. 代码块

使用三反引号创建代码块：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, TUI!" << std::endl;
    return 0;
}
```

也可以使用其他语言：

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("World"))
```

## 8. 表格语法

### 基本表格

| 名称   | 类型     | 描述           |
|--------|----------|----------------|
| parse  | 函数     | 解析 Markdown  |
| render | 函数     | 渲染字符画     |
| feed   | 方法     | 流式输入处理   |

### 对齐表格

| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 左     |   中     |     右 |
| AAA    |   BBB    |    CCC |
| 数据1  |  数据2   |  数据3 |

### CJK 宽字符表格

| 功能     | 状态 | 说明                   |
|----------|------|------------------------|
| 表格解析 | 完成  | 支持 `\|` 转义管道符   |
| 宽度计算 | 完成  | CJK 双宽 + emoji 支持  |
| 对齐渲染 | 完成  | 左/中/右三种对齐方式   |
| 流式缓冲 | 完成  | TableBuffer 状态机    |
