## 📌 通用角色基底（所有图都要满足，保持统一）

所有 10 张图的角色特征必须与用户提供的参考图完全一致：

| 项目 | 固定要求 |
|------|---------|
| 画风 | 日式 Q 版 SD 大头小身 chibi，2~3 头身，二次元表情包风格 |
| 描边 | 全身所有上色区 2~3px 粗细纯黑色实线描边，日式漫画线稿感 |
| 上色 | 平涂为主，少量柔和渐变阴影，颜色饱和鲜艳不发灰 |
| 背景 | 纯白背景，无任何多余装饰或阴影地面 |
| 头发 | 亮蓝色柔顺长发及腰，发尾蓬松微卷；头顶 **双分叉双呆毛**（U形左右翘，根部分叉）；表面 5~6 处椭圆形白色反光高光块 |
| 发夹 | 头发右侧（观众左侧）夹 **1 个立体白色小鲸鱼发夹**（带两只黑色小圆眼睛，面向观众） |
| 耳朵 | 两侧长出 **深蓝色鱼鳍耳朵**（代替人耳），横向展开像小翅膀；每只鱼鳍表面 2~3 个白色小圆亮点装饰 |
| 项圈 | 深蓝色细 choker 颈圈，下方挂 **两个连接在一起的白色三瓣爱心小吊坠**（或一颗白爱心） |
| 上衣 | 白色长袖水手服衬衫，袖口蓝白双条纹镶边；双层翻领（外沿宝蓝色宽边+内白色窄边 V 字）；胸前宝蓝色缎带大蝴蝶结，蝴蝶结正中心镶一个 **立体纯白迷你小鲸鱼圆扣** |
| 下装 | 宝蓝色百褶短裙，竖向褶皱清晰，裙摆微散开 |
| 尾巴 | 身后右下方一条大大的蓝色渐变鲸鱼尾，两叶向上翘起；尾巴表面有淡淡的鱼鳞弧形纹理 + 竖向 5~6 个白色小圆斑点 |
| 气泡 | 画面左上方一个 **大型圆形白色对话气泡**（漫画风），深蓝色粗描边，气泡底部尖尾指向角色嘴；内部深蓝黑色宋体/黑体写两行中文解说词（按每张图替换即可） |

> ⚠ 一致性规则：**每张图只能改动「表情 + 手的动作/手持道具 + 气泡两行字」**，上面的基底特征绝对不可以变动，否则整角色就不统一啦。

## 📝 如何修改一张图（示例）

如果你想把 **05 Token 压缩** 的气泡文案改成「超了先裁老对话」，只需改 Prompt 最后两行：

```diff
  【气泡文字】气泡内深蓝字体两行中文：
- 第一行：Token超了不会报错
- 第二行：先裁最老对话哒~
+ 第一行：上下文不够别担心
+ 第二行：先裁老对话补空间
```

如果你想把 **09 MCP** 的道具从「网线」换成「两台小计算机用虚线连起来」，只需替换【动作/道具】段落即可，基底和表情部分原封不动。
